# Intelligent AI Attendance System

An AI-powered attendance management system that uses face recognition and voice interaction to automate attendance workflows.

## Project Components

### AI Attendance Application
Main AI application responsible for attendance processing, face-based recognition and voice interaction.

### Landing Page
Web interface that introduces the project and provides access to the attendance application.

## Key Features
- Face-based attendance workflow
- Voice-based interaction
- Automated attendance processing
- Python-based backend
- Web landing interface
- Modular application architecture
